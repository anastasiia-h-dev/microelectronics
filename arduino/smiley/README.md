##This is a simple Arduino project

On every click smiley's face changes, every fifth click text appears.

Requisites:
```
Arduino UNO board
I2C Display
breadboard
jumperwires
button
resistor
```

Arduino board is connected via cable to a adapter which is directly connected to 220V socket.
